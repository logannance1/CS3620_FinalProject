- Clone the project
- In CS3620_FinalProject dir
- Make a venv by running python -m venv env
- Activate it
- Run pip install -r requirements.txt
- cd into project dir
- Run python manage.py runserver
- Register
- Login
  
On the dashboard, your portfolio chart might look empty as it defaults to $10,000.
As you make trades you will see your portfolio value change overtime.
Your history is only saved daily, so you might not be able to see changes in your portfolio history on the first day you run it.
